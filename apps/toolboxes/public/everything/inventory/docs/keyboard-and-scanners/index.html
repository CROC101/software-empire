Keyboard shortcuts and scanner behaviour

What every key does, how a hardware scanner is recognized, and which codes the camera reads.

crocwork·Product documentation·2 min read
On this page

  2. Hardware scanners
  3. Camera scanning, and typing

Keyboard shortcuts

Shortcuts
KeysWhat happens
Ctrl or Cmd + KOpen quick search from anywhere, unless a dialog is already open.
/Open quick search while no text field is focused.
Up and DownMove through the results.
Home and EndJump to the first or last result, while the search box is empty.
EnterOpen the highlighted result, or the product an exactly matching code names.
Alt or Option + EnterEdit the highlighted product instead of opening it.
EscapeClose the topmost dialog, sheet, or quick search.
Shift + clickExtend a selection across the product rows in between.
TabMove to the next field, including down a count sheet or a basket.

Hardware scanners

A USB or Bluetooth scanner acts as a keyboard: it types the code and presses Enter. Inventory recognizes that as a scan when the keystrokes arrive faster than a person types, run to at least four characters, and end in Enter. A Shift pressed for an uppercase character is part of the burst, not a break in it.

Scanning is picked up on the Products list, the stocktake sheet, and the take-out basket. It is ignored while a text field is focused or a dialog is open, so it never steals what someone is writing; in those places, the field in front of you is the scanning target instead. Quick search is one of them, which makes it a convenient place to scan from anywhere in the app.

Camera scanning, and typing

Where the browser provides barcode detection, a camera permission, and a secure connection, the scan dialog reads EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, ITF, Codabar, and QR codes. There is no bundled decoder as a fallback, because one would cost more to download than the rest of the app; browsers without detection are told so plainly.

Continuous mode keeps the dialog open for the next item and pauses the camera while a dialog it opened is in front of it. Every scan dialog also has a plain text field, so typing the code always works.

Focus, announcements, and motion

Navigating moves keyboard focus into the view that just loaded, and controls that rebuild themselves, such as sort headings, filter chips, and checkboxes, hand focus to their replacement rather than dropping it. Long lists that rebuild, like the count sheet, update rows in place so the field you are typing into survives.

Toasts, the offline banner, result counts, and count progress are announced as they change. Where your system asks for reduced motion, the app honours it, including the count sheet’s scroll to a freshly scanned row.
