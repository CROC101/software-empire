Planning and review

Running and reviewing a stocktake

Count a defined scope, inspect the differences, and keep the resulting report.

crocwork·Product documentation·2 min read
On this page
  1. Choose what you will count
  2. Record actual quantities
  3. Review and commit

Choose what you will count

Open Stocktake and choose the scope to count. Use a manageable location or selection when a complete inventory count would be disruptive. A blind count hides expected quantities while counting.

Print the count sheet if you work on paper, or enter counts in the app. Where shelf codes are available, order the sheet by bin so the count follows the room.

Record actual quantities

Enter the physical count for each item. Scanning can help identify the product being counted. Leave an item uncounted if it has not been checked; an entered zero means you counted it and found none.

Coordinate stock movements during the count. Recheck unusual differences against locations, packs, recent receipts, and items taken out before accepting a correction.

Review and commit

Review the count before committing it. The review distinguishes what was counted and skipped and shows the expected balance, counted balance, change, and value at cost. Committing writes one recount adjustment per changed product, after an automatic snapshot.

A count scoped to a location sets that location’s balance. A count of everywhere states the product’s total instead, and the difference lands in the product’s own location, drawing other places down only when that one cannot absorb a shortfall.

After committing, open the saved count report to print it or export CSV. Older saved counts are reduced to their totals, so export detailed reports you need to retain for later reviews.
