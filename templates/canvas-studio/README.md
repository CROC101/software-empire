# Canvas Studio

เว็บออกแบบกราฟิก หน้าเทมเพลต โปรเจกต์ ชุดแบรนด์ แอปเสริม

A crocwork template, inspired by [Canva](https://www.canva.com). Live preview: the Templates page of the crocwork Design Registry.

Canva and its logo are trademarks of their owner. This template is not made by, endorsed by or
connected to them; the names, brand and sample data here are our own. You may copy it, change it
and use it in your own projects.

## Run it

```sh
npm ci
npm run dev
```

`npm run build` writes a static site to `out/`. Set `TEMPLATE_BASE=/some/path` before the build to
serve it under a sub-path (that is how the preview runs under `/tpl/canvas-studio`).
