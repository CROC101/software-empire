# Sonora

เครื่องเล่นเพลง ค้นหา คิวเพลง เนื้อเพลง บัญชี

A crocwork template, inspired by [Spotify](https://open.spotify.com). Live preview: the Templates page of the crocwork Design Registry.

Spotify and its logo are trademarks of their owner. This template is not made by, endorsed by or
connected to them; the names, brand and sample data here are our own. You may copy it, change it
and use it in your own projects.

## Run it

```sh
npm ci
npm run dev
```

`npm run build` writes a static site to `out/`. Set `TEMPLATE_BASE=/some/path` before the build to
serve it under a sub-path (that is how the preview runs under `/tpl/sonora`).
