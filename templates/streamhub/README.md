# StreamHub

เว็บวิดีโอ หน้าแรก หมวด ช่อง เพลย์ลิสต์ หน้าดู ไลฟ์ และอัปโหลด

A crocwork template, modelled on a video site you already know. Live preview: the Templates page
of the crocwork Design Registry.

Everything here is safe for work: the sample videos are open movies (Big Buck Bunny, Sintel and
others) and the rest of the data is made up. This template is not made by, endorsed by or
connected to any site it resembles; the names, brand and sample data are our own. You may copy
it, change it and use it in your own projects.

## Run it

```sh
npm ci
npm run dev
```

`npm run build` writes a static site to `out/`. Set `TEMPLATE_BASE=/some/path` before the build to
serve it under a sub-path (that is how the preview runs under `/tpl/streamhub`).
