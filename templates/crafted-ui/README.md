# Crafted UI

คลังคอมโพเนนต์ ดูตัวอย่างสด คัดลอกโค้ด หน้าราคา

A crocwork template, inspired by [21st.dev](https://21st.dev). Live preview: the Templates page of the crocwork Design Registry.

21st.dev and its logo are trademarks of their owner. This template is not made by, endorsed by or
connected to them; the names, brand and sample data here are our own. You may copy it, change it
and use it in your own projects.

## Run it

```sh
npm ci
npm run dev
```

`npm run build` writes a static site to `out/`. Set `TEMPLATE_BASE=/some/path` before the build to
serve it under a sub-path (that is how the preview runs under `/tpl/crafted-ui`).
